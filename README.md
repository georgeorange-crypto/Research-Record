# 科研实习工作记录

这是一个面向查看者的工作记录入口，用于浏览每日汇报、阶段进展、周报、阅读笔记和留言点评归档。

在线访问：

[https://georgeorange-crypto.github.io/Research-Record/](https://georgeorange-crypto.github.io/Research-Record/)

## 快速查看

打开首页后，可以直接看到当前展示的工作汇报。页面会优先展示当天日报；如果当天还没有日报，则展示最近一次工作记录，并在页面顶部提示。

首页还会显示四个概览信息：

- 已记录日报天数
- 最近一次更新时间
- 本月记录数量
- 最近一篇周报

## 页面入口

| 页面 | 用途 |
| --- | --- |
| `index.html` | 今日汇报首页，适合快速查看最近工作进展。 |
| `archive.html` | 日报归档，按时间倒序查看全部日报。 |
| `weekly.html` | 周报页面，查看最近周报和历史周报入口。 |
| `papers.html` | 阅读笔记页面，查看资料阅读与思考记录。 |
| `milestones.html` | 阶段性里程碑，查看阶段成果和重要节点。 |
| `feedback.html` | 留言点评区，查看反馈入口和自动归档记录。 |

## 文件目录对应内容

| 目录或文件 | 内容说明 |
| --- | --- |
| `reports/` | 每日工作汇报，文件名格式为 `YYYY-MM-DD.md`。 |
| `weekly/` | 周报记录，可按周编号或日期命名。 |
| `paper-notes/` | 阅读笔记、资料摘要和思考记录。 |
| `milestones.md` | 阶段性成果、重要节点和后续计划。 |
| `feedback/feedback-log.md` | 留言点评归档，由自动化流程生成。 |

## 日报内容结构

每篇日报建议包含以下栏目：

```markdown
# YYYY-MM-DD 工作汇报

## 今日目标

- 

## 今日完成

- 

## 事务缘由

- 

## 遇到的问题

- 

## 明日计划

- 

## 思考与总结


```

其中 `事务缘由` 用于说明当天工作量受到影响的客观原因，例如课程考试、阶段答辩、材料提交、外出事务或其他临时安排。没有特殊情况时可以填写 `无`。

## 留言点评

页面提供专门的留言点评入口。查看者可以在 `feedback.html` 中进入留言区，提交对工作记录、阶段进展或后续安排的建议。

留言提交后，自动化流程会将带有 `page-feedback` 标签的留言和后续回复整理到：

```text
feedback/feedback-log.md
```

随后页面会自动重新部署，`feedback.html` 会展示最新的归档记录。

## 自动更新

仓库包含自动化流程：

- 当日报、周报、阅读笔记、里程碑或留言归档发生变化时，自动重新生成静态页面。
- 每天北京时间 06:00 自动生成并部署页面。
- 每天北京时间 23:45 检查当天日报是否存在；如果不存在，会自动创建空白日报模板。
- 留言或点评更新后，会自动整理归档并刷新页面。

## 适合的查看方式

- 查看当天进展：打开首页。
- 回看历史日报：进入日报归档。
- 了解阶段成果：进入阶段性里程碑。
- 查看阅读积累：进入阅读笔记。
- 留下建议或问题：进入留言点评区。
